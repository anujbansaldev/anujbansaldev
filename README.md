### 👋 About Me

I am a **Freelance Web Developer** and **Full Stack Developer** based in **Indore, Madhya Pradesh**, **India**, working with clients across India and internationally. As a specialized **Next.js Developer**, **MERN Stack Developer**, and **Payload CMS Developer**, I engineer high-performance SaaS web applications, custom internal tools, and modern headless CMS platforms focused on speed, clean architecture, and maximum search engine conversion.

My focus is on building software that scales effortlessly — combining modern **Next.js 15 & React 19** frontends with robust **Node.js, Express, and MongoDB** server architectures, sub-second API performance, and hardened Linux server infrastructure.

---

### 📊 Engineering Impact & Highlights

- 🚀 **270+ Client Applications Powered** — Architected and deployed a centralized financial calculation engine in `Node.js`, `Express`, `MongoDB`, and `Redis` powering production client platforms with sub-40ms latency.
- 🛡️ **150+ Enterprise Portals Hardened** — Consolidated distributed client portals into a unified `Next.js` monorepo with 48-hour security vulnerability response protocols.
- ⚡ **100/100 Core Web Vitals Standard** — Engineered production client applications for instant page loads, server-side rendering, and complete On-Page SEO optimization.
- 🔒 **Granular RBAC Architecture** — Developed standalone multi-role authentication modules with HTTP-only cookies and bcrypt hashing.
